# MACNICA WMS 离线演示

## 打开方式

解压或复制整个 `WMS-Demo` 文件夹，双击 `index.html`，用 Chrome 或 Edge 打开。无需安装 Node、Python 或任何依赖，也不需要联网。请保留 `assets` 文件夹和所有脚本、样式文件的相对位置。

建议在桌面浏览器以 100% 页面缩放展示，按 F11 可全屏。设计基准为 1672×941，同时适配 1366×768、1920×1080。较窄窗口可滚动页面或表格。

## 建议演示顺序

1. 在登录页切换主题、密码显隐、UAT/FUAT 环境，然后点击 **Sign in**。
2. 在首页展示六个业务分区、新闻、To do 和 My tasks；用日期左右按钮和 **Today** 切换日期。
3. 点击 Inventory 卡片中的 **On-hand enquiry**，或底部同名按钮进入库存查询。
4. 初始显示原图的 **5 条记录**，MPN 为 `EPM240T100C5N`，数量合计 **2,033**。
5. 将 **Subinventory** 改为 `YKK-JB`，点击 **Search**：3 条记录、数量 **493**。
6. 再将 **Supplier lot** 填为 `MJ2`：1 条记录、数量 **181**。文本匹配忽略大小写。
7. 点击 **Clear**，保留组织 `MCHK_OU` 和仓库 `HKW`，其他条件和列筛选清空。
8. 在表格 **Hold** 筛选选择 `Yes`：4 条记录、数量 **1,033**；点击 **Qty** 表头切换升降序。
9. 打开 **Columns** 隐藏部分列；将 **Rows per page** 改为 `2` 演示翻页。筛选合计始终覆盖全部匹配记录。
10. 点击 **Export** 或 **Export results**，下载当前全部筛选结果（包含排序及可见列）的 UTF-8 BOM CSV；导出不受当前页码限制。
11. 使用顶部 **Home** 返回首页，通过右上角账号菜单 **Sign out** 退出。

## Home 新版交互

- **To do** 和 **My tasks** 默认折叠，仅保留标题栏，把释放的高度分配给中间六个业务竖条。点击标题可独立展开或收起；重新进入 Home 时恢复默认折叠状态。
- 顶部主菜单默认只保留紧凑图标。鼠标悬停到对应图标时，菜单名称和功能入口向右展开，移出后自动收起；点击或使用 Tab 键也能展开，Escape 可关闭。
- 六个业务竖条加高，默认选中 **03 Inventory**。点击任意列标题或进入列内按钮，会切换选中状态，带来轻微加宽、放大、深青色背景和阴影变化。
- 每列功能列表独立上下滚动，标题和底部 **Open …** 入口保持固定。支持鼠标滚轮、滚动条、键盘滚动和底部箭头；滚到末尾时箭头改为返回顶部。
- 为展示长列表，补充了 ASN lookup、Stock movement、Lot traceability 等导航示例。这些新增入口展示本地说明，不连接真实业务。
- 使用系统“减少动态效果”设置时，关闭动画和滚动过渡。

## 查询规则与数据

- 表单中的所有字段都连接本地演示数据。文本按包含匹配，下拉精确匹配；日期、Locator 和标准日期码区间均包含起止边界。
- **Search** 或 Enter 应用表单条件。列筛选即时生效，并与已应用的表单条件叠加。
- **Refresh** 根据已应用条件重算；未点击 Search 的表单编辑不会改变已应用条件。
- 日期起点晚于终点等非法区间会显示提示，保留上次有效结果。
- **Clear** 同时清除可选条件、列筛选和排序；列显隐设置保留。至少保留一列。
- 五条可见库存记录来自设计图；供应商、PO、ASN、收货号等补充属性为用于筛选的虚构数据。
- 演示日期时间固定为 2026-10-27 10:14 AM；新闻日期和维护公告沿用参考图。

## 本次功能边界

实际可操作：模拟登录、页面跳转、首页日期、任务区折叠、新闻说明、查询区折叠、组合筛选、列筛选、排序、列显隐、分页、刷新、CSV 导出及退出。

Saved views、Group by、拖拽分组区域及其余业务模块显示说明弹窗。没有真实分组、视图持久化、入出库业务、后端接口、真实账号认证或手机专属布局。帮助与密码入口展示本地说明，不发送邮件或打开外部服务。

## 文件说明

- `index.html`：离线入口、弹窗及状态提示。
- `styles.css`：视觉还原与桌面尺寸适配。
- `app.js`：三页布局及交互，含主题切换和浏览器本地偏好保存。
- `data.js`：五条演示记录、筛选排序和 CSV 逻辑。
- `assets/`：本地图像与图标。Logo、仓库线稿、新闻照片通过 SVG 视口局部显示参考图；页面文本、控件和表格均由 HTML 实现。
- `tests.cjs`：开发者可用 `node tests.cjs` 执行逻辑和离线依赖检查；运行 Demo 无需执行测试。
- `previews/`：三页实际渲染截图，以及新版首页菜单展开、功能列表滚动预览。
- `VALIDATION.md`：本次验证结果与验证方式。

界面优先使用 Windows 自带 Bahnschrift、Segoe UI 字体，其他系统回退到可用字体，因此不同系统可能有轻微字形差异。
